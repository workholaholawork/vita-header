# ТЗ: доработка шапки сайта «Вита»

> [!IMPORTANT]
> Файлы `index.html`, `vita-header-exact.css`, `vita-header-exact.js` и каталог `assets` в корне — только визуал для просмотра и сверки через GitHub Pages. Разработчикам не нужно переносить этот код на сайт или использовать его как основу внедрения.
>
> Все подготовленные для разработчиков файлы находятся только в каталоге [`bitrix-handoff`](bitrix-handoff). Порядок внедрения описан в этом README.

## Файлы для внедрения

- [`bitrix-handoff/header-custom.css`](bitrix-handoff/header-custom.css) — дополнительные стили;
- [`bitrix-handoff/header-custom.js`](bitrix-handoff/header-custom.js) — скрытие верхней мобильной панели после начала прокрутки;
- [`bitrix-handoff/header-snippets.html`](bitrix-handoff/header-snippets.html) — готовые фрагменты разметки.

ПРЕДЛАГАЕТСЯ (если что-то не так, пишите :)) на production переносить только необходимые файлы из `bitrix-handoff` согласно инструкции ниже. Каталог `assets` на production не переносить.

## 1. Подключение

Скопировать:

- `header-custom.css` → `в нужное место, например: /local/templates/aspro-medc2/css/header-custom.css`;
- `header-custom.js` → `в нужное место, например: /local/templates/aspro-medc2/js/header-custom.js`.

В `header.php` шаблона подключить после штатных стилей и скриптов:

```php
<?php
\Bitrix\Main\Page\Asset::getInstance()->addCss(SITE_TEMPLATE_PATH . '/css/header-custom.css');
\Bitrix\Main\Page\Asset::getInstance()->addJs(SITE_TEMPLATE_PATH . '/js/header-custom.js');
?>
```

## 2. Разметка `header.php`

Код блоков находится в [`header-snippets.html`](bitrix-handoff/header-snippets.html).

1. **Десктоп:** удалить старую колонку контактов Краснодара. Перед оставшимся телефоном Сочи вставить `.header-main-regions`; колонке телефона добавить класс `.header-contact-primary`. Порядок: логотип → регионы → `+7 (988) 244 44 86` → расчёт стоимости → заказ звонка. Названия регионов — `font-weight: 600`.
2. **Верхняя мобильная контактная панель:** непосредственно перед `#mobileheader` вставить `#mobile-top-contacts`. Она показывается только до 991 px и скрывается после начала прокрутки. Названия регионов — `font-weight: 600`.
3. **Мобильная белая шапка:** внутри `.mobile_header_top` оставить штатный бургер слева и штатный логотип; удалить `.right-icons` с поиском; после логотипа вставить `.mobile-header-record`. Параметры `data-event="jqm" data-param-id="19" data-name="record_online"` используют штатное окно Bitrix — проверить ID формы на production.
4. **Поиск в бургере:** первым элементом внутри `#mobilemenu .wrap`, перед `.menu.top`, повторно вывести существующий компонент `bitrix:search.title`. Использовать тот же шаблон и параметры, что у десктопного поиска, но задать уникальные `INPUT_ID=title-search-input_mobile` и `CONTAINER_ID=title-search_mobile`. Новый поиск не писать, DOM десктопного поиска через JS не клонировать.
5. **Контакты в бургере:** старый `.mobile-contacts-menu` заменить блоком `.mobile-contacts-menu-v2`. Кнопки «Запись онлайн» и «Схема проезда» над ним и email под ним сохранить. Названия регионов — `font-weight: 600`.

Телефоны, время работы, email, ссылки и активный регион выводить из существующих настроек/включаемых областей Bitrix. Значения в сниппете — текущие значения макета, а не новый источник данных.

## 3. Главное меню

Менять в текущем источнике меню Bitrix, не прописывать статично в `header.php`.

Порядок верхнего уровня:

`Уход` → `Реабилитация` → `Забота` → `Размещение` → `Пансионаты` → `О компании` → `Цены` → `Отзывы` → `Контакты`.

- удалить `Галерея` и `Оформление`;
- вместо `Услуги` создать четыре обычных выпадающих раздела;
- состав разделов и URL взять из приложения ниже;
- `Пансионаты`, `О компании`, `Цены`, `Отзывы`, `Контакты` сохранить с текущим содержимым и URL;
- стрелки показывать только у пунктов с выпадающим списком;
- проверить тот же состав в фиксированной десктопной шапке `#headerfixed`.
